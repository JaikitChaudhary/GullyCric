# GullyCric 🏏

A real-time cricket scoring web app for gully cricket.

## Features
- Create match
- Live scoring (runs, wicket, undo)
- Real-time updates (Socket.io)
- 2 innings system
- Shareable match link
- View-only mode for others

## Tech Stack
- React (Vite + Tailwind)
- Node.js (Fastify)
- MongoDB
- Socket.io

## Getting Started

### Install
```bash
npm install
```

### Run
```bash
npm run dev
```

### Server
```bash
cd server && npm run dev
```

- Create match
